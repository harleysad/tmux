# tmux Configuration

A clean and modern `tmux` configuration for enhanced terminal productivity and aesthetics.

## Features
- Beautiful and minimal status bar
- Useful key bindings for efficient workflow
- Pre-configured plugins for extended functionality
- Easy customization

## Installation

Clone this repository into your `.config/tmux` directory:

```bash
git clone https://github.com/harleysad/tmux.git ~/.config/tmux
```

Then start or reload `tmux`:

```bash
tmux source-file ~/.config/tmux/tmux.conf
```

## Usage
- Launch `tmux` by running `tmux` in your terminal.
- Customize your configuration by editing `tmux.conf` as needed.

## Requirements
- [tmux](https://github.com/tmux/tmux) 3.0+
- [git](https://git-scm.com/)
